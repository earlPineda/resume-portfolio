# Earl Kevin E. Pineda — Resume & Portfolio

Interactive resume and developer portfolio for Earl Kevin E. Pineda, BSIT graduate
specializing in Web & Mobile Application Development.

## Run locally

```bash
npm install
npm run dev
```

Open the printed URL, usually `http://localhost:3000`.

## Build and production start

```bash
npm run build
npm run build:server
npm start
```

## Deploy to Render

- Connect this repository to Render as a **Web Service**.
- Build command: `npm install --legacy-peer-deps && npm run build && npm run build:server`
- Start command: `npm start`
- Declare the `PORT` environment variable supplied by Render; no other values are required.
